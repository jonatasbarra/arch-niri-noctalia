# Arch Linux + Niri + Noctalia Shell

My personal Arch Linux setup using Niri, Noctalia Shell v5, SDDM, Zsh, Starship, Alacritty, Fastfetch, and a shared `/data` development partition.

## Stack

- Arch Linux
- Niri Wayland compositor
- Noctalia Shell v5
- SDDM with Sugar Candy theme
- Zsh + Starship
- Alacritty
- Fastfetch mini rice
- Bibata cursor
- `/data/Projects` development workspace

## Hardware

ASUS Zenbook 14 UX3405CA  
Intel Core Ultra 9 285H  
Intel Arc integrated graphics  
Wayland session with Niri

## Status

This setup is currently used as my daily Linux development environment.

## Notes

This repository contains personal dotfiles and documentation. It does not include private keys, credentials, browser data, or personal files.
